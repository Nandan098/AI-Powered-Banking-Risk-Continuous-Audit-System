# Resume Bullets — use only after you personally run and understand the project

- Built an end-to-end banking risk analytics pipeline in Python, engineering behavioral features from 200K synthetic transactions across customers, accounts, merchants and devices.
- Developed an Isolation Forest anomaly-detection layer and explainable rule engine using transaction velocity, customer baseline deviation, device novelty, location distance and channel behavior.
- Designed a configurable risk-scoring framework combining ML anomaly scores, rule evidence, behavioral signals and transaction context, then generated a prioritized audit-case queue.
- Published PostgreSQL-ready analytics and FastAPI endpoints and prepared Power BI tables for risk overview, transaction-risk analysis and continuous-audit monitoring.
