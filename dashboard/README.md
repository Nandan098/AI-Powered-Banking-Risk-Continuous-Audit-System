# Power BI Dashboard

## Dashboard name
**Banking Risk & Continuous Audit Dashboard**

## Pages
1. **Risk Overview** — portfolio-level transaction/risk KPIs and trends.
2. **Transaction Risk Analysis** — transaction-level risk scores, anomaly scores, rule evidence and filters.
3. **Continuous Audit Monitor** — open cases, priorities, reasons, channels, case status and model-evaluation metrics.

Import the CSVs from `data/powerbi/`. The files are generated by `scripts/run_pipeline.py`.
